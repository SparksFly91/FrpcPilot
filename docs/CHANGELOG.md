# 更新日志

本文件记录 Frpilot 各版本的更新内容。

---

## v1.0.0（2026-10-14）

### 🎉 首个正式版本发布！

Frpilot 迎来 1.0.0 正式版 —— 从「手写 frpc.toml」到「点几下就能跑起来」，frp 的日常管理终于有了顺手的图形界面。

### ✨ 新增功能

- **仪表盘**：一屏总览系统信息（主机名 / 系统 / 架构 / IP）与服务器、隧道数量；选择 frpc 版本后「一键启动 / 停止」，并实时回显运行日志与进程退出信息。
- **服务器管理**：frps 服务器的新增 / 编辑 / 删除，支持地址、端口、鉴权 Token、传输协议、TLS、置顶与排序；同一时间仅允许启用一台服务器。
- **隧道管理**：覆盖 TCP / UDP / HTTP / HTTPS / STCP / XTCP / SUDP / TCPMUX 等代理类型，支持自定义域名、子域名、URL 前缀、密钥、加密与压缩、带宽限制、Proxy Protocol、健康检查、负载均衡等高级配置，并统一管理启用 / 置顶 / 排序。
- **Frpc 下载管理**：在线拉取 Frp 官方版本列表，按平台与架构筛选；支持下载（含进度与解压状态）、导入本地已下载的 frpc / frps、删除与复制下载直链。
- **一键启动与实时日志**：依据所选版本、已启用的服务器与隧道自动生成 frpc.toml 并拉起独立进程，通过 `frpc-log` / `frpc-exit` 事件实时推送日志。
- **应用内自动更新**：接入 Tauri updater 与 process 插件，启动时静默检查更新；支持手动检查、「忽略该版本」与下载进度展示，更新说明以 **Markdown** 渲染，安装完成后自动重启。
- **关于页面**：集中展示项目介绍、技术栈、使用流程、开源地址与版本信息，并提供「检查更新」入口。
- **国际化**：内置简体中文 / English，语言选择持久化，并与 Ant Design Vue 组件语言包联动。
- **明暗主题**：基于 `useDark` 一键切换，Tailwind 暗色变体与 Ant Design Vue 暗色算法同步，选择持久化。
- **自定义标题栏**：Windows 与 macOS 双套方案（macOS 还原原生红绿灯），支持拖拽移动窗口；顶部栏集成语言 / 主题 / 检查更新 / GitHub / 设置与窗口控制按钮。

### 🎨 优化

- **透明磨砂玻璃视觉**：侧边栏、内容区与卡片统一为圆角 + 背景模糊的半透明面板，明暗主题下均有细腻的层次与投影表现。
- **统一弹窗布局**：表单弹窗与更新弹窗统一为「标题 / 底部按钮固定、内容区滚动」的结构，内容过多时仅弹窗主体滚动，并限制最大高度。
- **macOS 标题栏细节**：隐藏右侧冗余的最小化 / 关闭按钮，禁用 macOS 下并不需要的最大化（绿灯）按钮。
- **下载卡片交互**：状态标签、大小 / 下载次数 / 发布日期等元信息与操作按钮重新排布，下载与解压进度直观可见。

### 🚀 工程

- 后端采用 **Rust + Tauri 2**，使用 `sqlx`（SQLite）持久化服务器、隧道与 Frpc 下载记录，并通过 `tauri-helper` 统一注册命令。
- 前端技术栈：**Vue 3 + TypeScript + Vite 8 + Pinia + Vue Router + Vue I18n 11**，UI 使用 **Ant Design Vue 4 + Tailwind CSS 4**，借助 `unplugin-auto-import` / `unplugin-vue-components` 实现按需自动导入。
- 开启 `createUpdaterArtifacts` 并结合签名密钥生成更新产物与 `latest.json`，打通应用内自动更新链路。
- 新增 GitHub Actions 发布工作流，覆盖 **Windows x64 / macOS Apple Silicon / Linux x64** 多平台构建，并自动从本文件提取对应版本说明作为 Release 正文。
- 补充多平台应用图标，项目以 **Apache License 2.0** 开源。
